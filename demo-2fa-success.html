📱 How the 2FA Flow Works

  1. Setup Phase:
    • User visits /settings/2fa page
    • System generates a unique TOTP secret
    • QR code is created containing otpauth:// URL
    • User scans QR code with Google Authenticator
  2. Verification Phase:
    • User enters 6-digit code from their authenticator app
    • System verifies the code using speakeasy.totp.verify()
    • If valid, 2FA is enabled for the user
  3. Login Phase:
    • After password authentication, user must enter TOTP code
    • System verifies the code before completing login

🛠 Technical Implementation

Database Schema Changes:

model User {
  id               String    @id @default(cuid())
  name             String?
  email            String?   @unique
  emailVerified    DateTime? @map("email_verified")
  password         String
  sessions         Session[]
  
  // 2FA TOTP fields
  twoFactorSecret  String?   @map("two_factor_secret")
  twoFactorEnabled Boolean   @default(false) @map("two_factor_enabled")
 
  @@map("users")
}

Key API Endpoints:

  • POST /api/auth/2fa/setup - Generate QR code
  • POST /api/auth/2fa/verify - Verify TOTP token
  • POST /api/auth/2fa/enable - Enable 2FA after verification
  • POST /api/auth/2fa/disable - Disable 2FA
  • GET /api/user/2fa-status - Check 2FA status

React Components:

  • Setup2FA - QR code generation and setup flow
  • Verify2FA - TOTP code verification during login
  • Settings page at /settings/2fa for management
